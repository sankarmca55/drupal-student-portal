# Drupal 11 – Student Portal

## Project Overview
A Student Portal web application developed using Drupal 11. This project is part of my practical learning journey in Drupal development, PHP and Twig.

## Technologies Used
- Drupal 11
- PHP 8.4
- Twig 3
- HTML5
- CSS3
- MariaDB
- DDEV
- Git and GitHub

## Features
- Custom Drupal theme
- Responsive homepage design
- Student information cards
- Twig variables and filters
- Twig loops and conditional statements
- Dynamic student status display
- Admission status based on login state

## Project Structure
- `web/themes/custom/student_portal_theme/` – Custom Drupal theme
- `web/themes/custom/student_portal_theme/templates/` – Twig templates
- `web/themes/custom/student_portal_theme/css/` – Custom CSS

## Installation
1. Clone this repository.
2. Start the project using DDEV.
3. Install project dependencies using Composer.
4. Import the database if a database backup is available.
5. Start the Drupal website using DDEV.

## Learning Goals
- Improve Drupal 11 development skills.
- Understand Twig templating.
- Learn PHP and Drupal APIs.
- Build practical Drupal features.
